# 📚 MemoRecite · Lock Screen Memory

> No need to open the app — see what you need to review right on your lock screen.
> Turn your fragmented time into automatic review — perfect for exams, vocabulary, law, poetry, and more.

---

## ✨ Features

- 🔒 **Auto pop-up on lock screen**: Wakes up the screen, shows full-screen cards, and vibrates
- 🧠 **Ebbinghaus forgetting curve**: Scientific review intervals (5min → 30min → 12h → 1d → ... → 60d)
- 📚 **Unlimited nested groups**: Groups → Subgroups → Sub-subgroups, organize as deep as you want
- 🖼️ **Rich cards with images**: Text + images (vocabulary with pictures, herb/plant recognition)
- 🎯 **Three-level self-rating**: Forgot / Vague / Remembered — the algorithm adjusts the next review time
- ⏰ **Batch until done**: A group keeps popping up automatically until every card is reviewed
- 📊 **Progress statistics**: See each group's mastery at a glance
- 💻 **PC bulk upload**: Phone opens a mini WiFi server, upload text + images from your browser
- 🌐 **Multi-language UI**: 中文 / English / 日本語
- 💾 **Auto backup**: Multi-level backup (hourly / daily / weekly / monthly / snapshots) — never lose data
- 🔇 **Do Not Disturb hours**: Silent period at night (default 00:00–06:00)
- 📈 **Per-card custom curve**: Each card can have its own review intervals
